# How to Read This Repository

This repository contains the testable version of the SEHAI framework (Standard of Engagement for Healthcare Artificial Intelligence) and the complete mapping of all 13 standards against the core Minimum Necessary Information (MNI) matrix.

## Start here (recommended order)

1. **MNI_Testable_Requirements_Matrix_v1.0.md**  
   This is the foundation. It turns Standard 1 into 30 clear, testable requirements. Everything else is measured against this matrix.

2. **Master_Coverage_Matrix.md**  
   A single table showing how Standards 2–13 relate to each of the 30 MNI requirements (Supports / Partially supports / Silent / Contradicts).

3. **Architecture_Findings.md**  
   The main intellectual results of the mapping work (how the standards actually fit together).

4. **Individual Mapping Reports** (Mapping_Standard_02 … Mapping_Standard_13)  
   Detailed, requirement-by-requirement analysis for each standard.

5. **Candidate_Revisions_MNI_v1.1.md**  
   Proposed improvements to the MNI matrix based on what the later standards revealed.

6. **Test_Instrument_Library.md**  
   All the evaluation tools (TI-1 through TI-16) collected in one place.

## What the verdicts mean

- **Supports** — The standard actively helps satisfy or strengthens the MNI requirement.
- **Partially supports** — The standard touches the requirement but does not fully cover it.
- **Silent** — The standard says nothing relevant about that requirement.
- **Contradicts** — The standard conflicts with the MNI requirement (none were found).

## Current status

- All 13 standards have been mapped (360 requirement-level comparisons).
- Zero contradictions were found.
- The MNI matrix is at version 1.0. A list of candidate improvements for v1.1 is included.

## Who this is for

- Researchers and peer reviewers evaluating the internal coherence of the SEHAI framework
- Organizations considering adopting or testing against these standards
- Anyone who wants a clear, auditable view of how the 13 standards relate to one another

If you are new to the project, read the MNI matrix first, then the Master Coverage Matrix. That will give you the fastest overview.
