# SEHAI — Standard of Engagement for Healthcare Artificial Intelligence

**Minimum Necessary Information (MNI) and the Full Suite of 13 Standards**

This repository contains the testable requirements matrix for Standard 1 (Minimum Necessary Information) and the systematic mapping of the remaining 12 SEHAI standards against it.

## What is in this repository

- **Core Matrix**: The 30-row Testable Requirements Matrix for Minimum Necessary Information (MNI) — the foundation of the framework.
- **Original Standards**: The full text of all 13 SEHAI standards.
- **Mappings**: Individual mapping reports showing how each standard relates to the MNI matrix (Supports / Partially supports / Silent / Contradicts).
- **Synthesis**: Architecture findings, candidate revisions, and the complete Test Instrument Library.

## Current Status

- MNI Testable Requirements Matrix: **v1.0** (finalized)
- Standards mapped against MNI: 2–12 (Standard 13 pending final integration)
- Contradictions found: **0**
- Candidate revisions for MNI v1.1: tracked in the Synthesis folder

## How to navigate

1. Start with the **MNI Testable Requirements Matrix** (the core rules).
2. Review individual **Mapping reports** to see how each later standard relates to MNI.
3. See the **Master Coverage Matrix** and **Architecture Findings** for the overall picture.
