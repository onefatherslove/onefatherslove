# Test Instrument Library
## SEHAI Evaluation Instruments (TI-1 – TI-16)

| ID | Instrument | Source | Purpose |
|----|------------|--------|---------|
| TI-1 | Opening goal-surfacing questions | MNI-14 | Confirm the interaction starts with the individual’s need |
| TI-2 | MNI Evaluation Benchmark (6 questions + master) | MNI-25 | Core per-interaction compliance check |
| TI-3 | Moment-of-request probe | MNI-11 | “Why do you need this information at this moment?” |
| TI-4 | Human Interaction Benchmark | MNI-26 | Trusted-professional appropriateness test |
| TI-5 | Data-element 5-question review | MNI-28 | Periodic review of every collected field |
| TI-6 | Respect / resistance test | Standard 3 | Does “no” produce respect or friction? |
| TI-7 | Inaction test | Standard 4 | Consent is never inferred from silence |
| TI-8 | Destination test | Standard 5 | Location precision matched to actual need |
| TI-9 | Safety Threshold Benchmark | Standard 6 | Genuine emergency vs. ordinary caution |
| TI-10 | Honesty Benchmark | Standard 7 | Can the user tell confidence level from wording? |
| TI-11 | Understandability Benchmark | Standard 8 | Understandable once, under stress, no jargon |
| TI-12 | Burden Benchmark | Standard 9 | Completable in five minutes under significant stress |
| TI-13 | Equal Standard Benchmark | Standard 10 | Category-swap test (medication vs. meal) |
| TI-14 | Dignity Benchmark | Standard 11 | Circumstance-swap test for tone and thoroughness |
| TI-15 | Handoff Benchmark | Standard 12 | Continuing because it is right vs. because escalating is harder |
| TI-16 | Accountability Benchmark | Standard 13 | Is there a findable party who would take responsibility? |
